SETUP GUIDE
  1. Create a webhook in your Discord server channel settings.
  2. Copy the webhook URL and paste it into this private field.
  3. Enable notifications and choose which statuses trigger alerts.
  4. Save, then send a test message to confirm it works.
Keep your webhook URL secret. Anyone with it may be able to post to your channel. If it leaks, delete or regenerate it in Discord.
